# digmore V0.1.1 — the sub-agent roster

Baseline: the skill as built at commit `da94c5a`, read 2026-08-19.

Marks: **(spec)** a stated cap · **(arithmetic)** caps multiplied, no total is stated ·
**[TBD]** the skill does not say · **[OPEN]** identified, not decided · **WRONG** the skill
contradicts itself · **MISSING** a capability nothing provides · **[DRAFT]** written from what the
skill does today, for Peter to replace. Each carries a `> **Peter:**` line to fill in.

**Purpose** is the first field on every agent: the one job it exists to do, in a sentence. Not when
it runs (**Phase**) and not what one dispatch covers (**One dispatch per**) — why it is a separate
agent at all. Every one is **[DRAFT]** today.

"Sent" means the path is written into the agent's prompt and it opens the file itself.

## 1. Scoping agent
