# digmore V0.1.1 — the sub-agent roster

Baseline: the skill as built at commit `da94c5a`, read 2026-08-19.

Marks: **(spec)** a stated cap · **(arithmetic)** caps multiplied, no total is stated ·
**[TBD]** the skill does not say · **[OPEN]** identified, not decided · **WRONG** the skill
contradicts itself · **MISSING** a capability nothing provides. Each carries a `> **Peter:**`
line to fill in.

"Sent" means the path is written into the agent's prompt and it opens the file itself.

## 1. Subject Scout

- **Phase:** Plan
- **One dispatch per:** the topic
- **Full run:** 1 (spec)
- **`--fast`:** 1 — less orienting, not none
- **Input**
  - *Task text:* the topic as the user phrased it, and the job — find out what this subject
    actually is: the vocabulary its own people use, the names that recur, the arguments live
    right now. Explicitly not the angles; those are the orchestrator's.
  - *Rule files sent:* `brain/output.md` — always, the line is in the dispatch template.
  - *Data files sent:* none.
- **Runs:** WebSearch, open-ended and unbudgeted.
- **Returns to main context:** JSON `orientation` — the queries it ran, the vocabulary the subject's own people
  use, the names that recur, the arguments live now.
- **Writes to disk:** nothing. What it read on the open web is not kept.
- **Log file:** `digmore/<slug>/cache/_progress/subject-scout.log` — one line before each step.
  Its return copy goes to `digmore/<slug>/cache/_returns/subject-scout.json`, which is what
  `validate.mjs` reads.
- **Size per dispatch:** large — reads a lot of the open web to hand back a little.
- **Dispatch site:** `plan_phase_a.md:23`
- **Concurrency:** n/a — single
- **Missing rules:** `anonymity.md` — the topic may carry the user's own company or product
  name, and this agent puts it straight into open-web searches.

  > **Peter:**
- **Missing functionality**
  - **MISSING** — it is the only unbudgeted searcher in the run, so it can spend the session's
    web-search quota before Extract starts.

    > **Peter:**

  - **MISSING** — nothing checks what it returns. Every branch query inherits its vocabulary,

    `schemas.md:205` still names the shape `scope`, but `scripts/schemas.json` has

## 2. Branch Researcher

- **Phase:** Extract
- **One dispatch per:** one branch — one angle paired with one source
- **Full run:** 18–36 (arithmetic: 3–6 angles × up to 6 sources)
- **`--fast`:** ~12 (2 angles × sources)
- **Input**
  - *Task text:* one angle `{label, query, rationale}`, one source name, the topic slug, the
    branch's fetch budget.
  - *Rule files sent:* `brain/output.md` — always. `brain/sources/<source>.md` — only if the
    orchestrator writes the path into the job text; `extract_phase_b.md:29` tells the searcher
    to read it, but that line sits in a file only the orchestrator sees.
  - *Data files sent:* none — this agent is the one creating material.
- **Runs:** `api.mjs reddit search` on Reddit · WebSearch with a `site:` filter on HN, Twitter
  and forums · plain WebSearch on the web source · on local, copies the user's named files into
  `cache/local/` · on HN, also `hackernews.mjs story <N>` per harvested item id.
- **Returns to main context:** JSON `branch-searcher` — `results[]` of
  `{url, title, relevance}`. Unbounded: the schema sets no `maxItems`, and `fetchesPerBranch`
  caps what gets *fetched*, not what gets returned. A branch that finds 200 candidates can
  return all 200.
- **Writes to disk:** `digmore/<slug>/cache/<source>/` — the search response, at that source's
  own filename: `search-<subs|sitewide>-<sort>-<window>-<qhash>.json` on Reddit,
  `item-<N>.json` per story on Hacker News, the copied file under its original name on local.
- **Log file:** `digmore/<slug>/cache/_progress/branch-researcher-<angle>-<source>.log`.
  Return copy: `digmore/<slug>/cache/_returns/branch-researcher-<angle>-<source>.json`.
- **Size per dispatch:** unclear — one search and a URL list on most sources, but on Hacker News it also fetches every story it harvested.
- **Dispatch site:** `extract_phase_b.md:11`
- **Concurrency:** all at once, capped only by the harness limit preflight reported
  (`extract_phase_b.md:13`).
- **Missing rules:** `recency.md` — every query must carry `after:<two years ago>`, and this
  agent writes the queries. `anonymity.md` — no user or company names in a query; same agent,
  same problem.

  > **Peter:**
- **Missing functionality**
  - **MISSING** — nothing dedupes URLs across branches before the next phase, so a page found
    by five branches is read five times by five Document Analysts. `audit.md` records
    cross-source duplicates, but afterwards, as a note.

    > **Peter:**

  - **MISSING** — it never reports how many candidates it discarded, so a branch that found 200
    URLs and kept 20 looks identical to one that found 20.

## 3. Document Analyst

- **Phase:** Extract
- **One dispatch per:** one document a Branch Researcher kept
- **Full run:** up to ~700 (arithmetic: 36 branches × `fetchesPerBranch` 20)
- **`--fast`:** up to ~60 (12 branches × 5)
- **Input**
  - *Task text:* one URL, its source, its branch, the branch's remaining fetch budget, and the
    claim shape — every claim needs a verbatim quote.
  - *Rule files sent:* `brain/output.md` — always.
  - *Data files sent:* the cached page under `cache/<source>/<name>`.
- **Runs:** `api.mjs reddit thread <id>` on Reddit · `fetch.mjs <url> --output
  digmore/<slug>/cache/<source>/<name>` on websearch and forums · nothing on HN, already
  fetched · then `fetch.mjs` again per extra page.
- **Returns to main context:** JSON `source-extractor` — `sourceQuality`, `publishDate`, and

  `maxItems`. Across ~700 dispatches this is the largest thing entering the main context.
- **Writes to disk:** `digmore/<slug>/cache/<source>/` — the fetched page, and one more file per
  extra page when it paginates: `thread-<id>.json` on Reddit, `<safe-name>` then `<safe-name>-p2`,
  `-p3` … for anything fetched with `fetch.mjs`.
- **Log file:** `digmore/<slug>/cache/_progress/document-analyst-<host>-<n>.log`.
  Return copy: `digmore/<slug>/cache/_returns/document-analyst-<host>-<n>.json`.
- **Size per dispatch:** unclear — one cached page, or up to 20 fetches if it follows a paginated document to its end.
- **Dispatch site:** `extract_phase_b.md:60`
- **Concurrency:** [TBD] — unspecified today.

  > **Peter:**
- **Missing rules:** `vetting.md` — it must return a `sourceQuality` value and the definitions

  `long-form.md` — it must follow a document past page 1, find the next-page link, stop when
  pages repeat, and count every page against the budget. `sources/<source>.md` — which command
  fetches on this source.
